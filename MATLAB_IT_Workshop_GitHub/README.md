# MATLAB IT Workshop Lab

MATLAB practical programs organized experiment-wise according to the IT Workshop / MATLAB Lab Manual.

## Experiments
1. Introduction to MATLAB Software Interface
2. MATLAB Variables and Miscellaneous Commands
3. Mathematical Operations on Matrices
4. Built-in Functions and Linear Equations
5. Plotting Data using MATLAB
6. MATLAB M-Files
7. Debugging M-Files
8. Control Flow and Operators
9. Image Acquisition & Pre-processing
10. Deep Learning-based Vision Algorithms (CNNs)

## VLAB
- Image Histogram
- Fourier Transform

## How to use
Open the required experiment folder in MATLAB and run the `.m` file.
For image experiments, place `image.jpg` in the same folder.
